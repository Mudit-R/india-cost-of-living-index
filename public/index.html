About the Custom Weights

This tool scales the standard household component weights based on your preferences to create a personalized Index.

For each category, use the slider to set its weight multiplier (1 to 10):
  • 1 : 0.1x weight (unimportant / low priority)
  • 5 : 1.0x weight (normal, baseline national weights)
  • 10 : 2.0x weight (very important / highest priority)

Categories analyzed: Housing, Grocery, Transport, Healthcare, Education, Electricity, Restaurant, Movies.
Index scale: Delhi = 100 (baseline). Lower values indicate greater affordability.
